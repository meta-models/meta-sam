# Changesets

Every pull request that changes a published package's behavior or public contract must add a changeset:

```sh
npm run changeset
```

Choose each directly changed package and its SemVer bump. Changesets expands the release through exact internal dependencies, so a parser bump also versions packages whose dependency manifests must change.

Merges to `main` update a rolling `chore: version packages` pull request. Merging that release pull request publishes only the planned package subset to the public npm registry in dependency order, after approval in the `npm` GitHub environment.

Do not hand-edit `release-plan.json`. It is generated by `npm run version-packages` inside the release pull request and consumed by the audited publisher after merge.
