# Protocol

This directory owns the language-neutral, normative protocol documentation shared by every implementation in this repository.

- [`sam3.md`](sam3.md) defines the supported SAM 3 text format and streaming outcomes.

Implementation-specific APIs and tooling belong under that implementation's directory. A protocol behavior change should update the normative document and add or update a case under [`../conformance/cases/`](../conformance/cases/).
